# Ukrainization localizer text for XMB (PSP)

вихідний текст strings.txt для українізації інтерфейсу XMB на PlayStation Portable (PSP). 

Проєкт працює на базі плаґіна [Localizer](https://code.google.com/archive/p/localizer-plugin/) від поляків.

## 🛠 Збірка

Щоб скомпілювати вихідний текст українізації у готовий мовний файл, використайте утиліту `Paxor.exe`, яка йде в архіві разом із плагіном Localizer.
